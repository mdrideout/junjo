Junjo gives your coding agent the building blocks and shared evidence needed
for **recursive self improvement**: investigate a failure, test a targeted
change, compare the outcomes, and show you what happened.

Two pieces fit into your existing stack:

- **Junjo Python SDK lives in your application.** It provides instrumentation,
  workflow and specialist-agent building blocks, local evaluation tooling,
  and a CLI and skills for your coding agent.
- **Junjo AI Studio runs as lightweight containerized services.** It stores
  telemetry, evaluation datasets, results, and execution history for
  investigation by coding agents and humans.

Your coding agent makes and tests changes. Your application runs the models,
tools, and evaluators. Studio connects the outcomes to the execution evidence.
Keep your supported agent framework, or build fully with Junjo.

## Get started

Start with one application feature you want to understand and improve.

<Steps>

1. **Set up Junjo AI Studio.**

   [Deploy Studio](/docs/studio/deployment/) to store traces, datasets, and
   evaluation results in an environment you control.

2. **Connect your application.**

   Configure [OpenTelemetry traces](/docs/observability/opentelemetry/).
   The [Python SDK](/docs/python/get-started/) provides native Workflows and
   Agents with additional execution and state diagnostics. See the integration
   guides in the sidebar for supported external runtimes.

3. **Connect your coding agent.**

   [Install the evaluation skill](/docs/python/evaluation/#give-a-coding-agent-the-runbook)
   matching your installed SDK. Your agent uses Junjo's CLI to discover the
   application's targets, manage datasets, run experiments, and inspect evidence.

4. **Improve one real feature.**

   Follow the [first improvement guide](/docs/recursive-self-improvement/).
   Declare a target and its evaluation criteria, establish a baseline, and
   compare a code or prompt change against the same locked dataset.
   Open the linked Studio evidence to review the result together.

</Steps>
